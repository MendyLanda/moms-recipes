# המתכונים של אמא
אתר עברי ציבורי ב־https://mendylanda.github.io/moms-recipes/ .

## תוכן ועריכה
- recipes.js: מתכונים מובנים, מזהים יציבים, כמויות, שלבים, הערות ומקור.
- tips.js: טיפים מהשיחות, לפי נושא. לכל טיפ קישור למתכון רלוונטי או לשיחת מקור.
- assets/: תמונות המחשה שנוצרו ב־AI, וגופן Heebo לשימוש מקומי.
- fonts.css, style.css, app.js, index.html: עיצוב והתנהגות.

כל עדכון לענף main מתפרסם ב־GitHub Pages. אין שירות שקורא שיחות מתוך האתר עצמו. מוגדרת באפליקציית Codex בדיקה יומית בשיחה המקורית, התלויה בגישה למקורות ולסביבת העבודה.

## כללי עדכון
יש לקרוא הודעות המשך ותיקונים, ולא להסתפק בהודעה הראשונה או בכותרת. חיפוש השיחות נטען בעמודים: יש לגלול ברשימת תוצאות החיפוש להיסטוריה ישנה יותר. מקור החשבון הוא Chrome בפרופיל ״מקווה אורג״, לא ״מושקי״.

אין להמציא כמויות או להעלות פרטים אישיים. אם חסרה כמות או קיימת סתירה, מציינים זאת. אין לסמן מתכון כמנוסה ללא תיעוד. עצה שאינה מתכון מלא מתאימה לאזור הטיפים. אין להפוך הצעה עתידית למתכון מלא שלא נכתב.

לכל מתכון חדש מוסיפים צילום המחשה מתאים ב־assets/<id>.jpg, או מגדירים image למזהה צילום תואם. אין להשתמש בתמונת מנה אחרת. תמונות הן המחשה ואינן תיעוד של הבישול בפועל. שומרים את הודעת ההמחשה באתר.

מעדכנים פרמטר גרסה בקישורי הקבצים ב־index.html לאחר שינוי, כדי למנוע טעינת גרסה ישנה ממטמון. שומרים על מזהים קיימים ועל קישורים ישירים למתכונים. בודקים חיפוש, סינון, פתיחה, רוחב נייד וטעינת תמונות. מאמתים build מוצלח ושהתוכן החי תואם לפני דיווח על פרסום.

## ניהול ישירות מהאתר
כפתור ״ניהול המחברת״ מאפשר להיכנס עם סיסמה, להוסיף ולערוך מתכונים ולהעלות תמונה. מחיקה מסירה מהתצוגה הציבורית ושומרת אפשרות שחזור בניהול.

האתר נשאר ב־GitHub Pages. בקשות הניהול נשלחות לשירות `moms-recipes-api` ב־Vercel (צוות `landa-tech`). נתוני העריכה נשמרים ב־Vercel Blob פרטי `moms-recipes-content`, בקובץ `content.json`; תמונות נשמרות בנפרד וגרסאות קודמות ב־`history/`. הסיסמה נשמרת כגיבוב scrypt במשתנה שרת `PASSWORD_HASH`, ומפתח החתימה ב־`SESSION_SECRET`. אין סיסמה או טוקן שרת בקבצים הציבוריים. התחברות מוגבלת לחמישה ניסיונות בכל 15 דקות לכתובת IP; הרשאת הניהול פגה אחרי שמונה שעות. ההרשאה נשמרת רק בלשונית ולא הסיסמה.

חשוב לעדכון היומי: יש לקרוא תחילה את `https://moms-recipes-api.vercel.app/api/manage`. שינויים מהאתר גוברים על `recipes.js`; מזהים ברשימת `deleted` לא יוחזרו בטעות. אין לדרוס עריכה ידנית או לשחזר מתכון שנמחק. אם מקור שיחה מתקן מתכון שנערך ידנית, יש לשלב את השינוי בזהירות או לדווח על התנגשות. העדכון היומי עדיין יכול להוסיף מתכונים חדשים לקובץ הבסיס; הם יופיעו באתר לצד העריכות. גיבוי פרטי של `content.json` לפני שינוי שירות מומלץ. שמירה משתמשת ב־ETag למניעת דריסת עריכה במקביל.

בדיקות: `npm ci && npm test`; בדיקת תחביר `node --check app.js && node --check admin.js && node --check api/manage.js`. פרסום שירות: `vercel --prod --scope landa-tech` מהתיקייה המקושרת. סודות וקובצי `.env*` ו־`.vercel` אינם נשמרים במאגר. שינוי פרטי ההתחברות נעשה במשתני הסביבה ב־Vercel ופרסום מחדש.
