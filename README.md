# המתכונים של אמא
אתר עברי ציבורי ב־https://mendylanda.github.io/moms-recipes/ .

## תוכן ועריכה
- recipes.js: מתכונים מובנים, מזהים יציבים, כמויות, שלבים, הערות ומקור.
- tips.js: טיפים מהשיחות, לפי נושא. לכל טיפ קישור למתכון רלוונטי או לשיחת מקור.
- assets/: תמונות המחשה שנוצרו ב־AI, וגופן Heebo לשימוש מקומי.
- fonts.css, style.css, app.js, index.html: עיצוב והתנהגות.

כל עדכון לענף main מתפרסם ב־GitHub Pages. אין שירות שקורא שיחות מתוך האתר עצמו. מוגדרת באפליקציית Codex בדיקה יומית בשיחה המקורית, התלויה בגישה למקורות ולסביבת העבודה.

## כללי עדכון
יש לקרוא הודעות המשך ותיקונים, ולא להסתפק בהודעה הראשונה או בכותרת. חיפוש השיחות נטען בעמודים: יש לגלול ברשימת תוצאות החיפוש להיסטוריה ישנה יותר. מקור החשבון הוא Chrome בפרופיל ״מקווה אורג״, לא ״מושקי״.

אין להמציא כמויות או להעלות פרטים אישיים. אם חסרה כמות או קיימת סתירה, מציינים זאת. אין לסמן מתכון כמנוסה ללא תיעוד. עצה שאינה מתכון מלא מתאימה לאזור הטיפים. אין להפוך הצעה עתידית למתכון מלא שלא נכתב.

לכל מתכון חדש מוסיפים צילום המחשה מתאים ב־assets/<id>.jpg, או מגדירים image למזהה צילום תואם. אין להשתמש בתמונת מנה אחרת. תמונות הן המחשה ואינן תיעוד של הבישול בפועל. שומרים את הודעת ההמחשה באתר.

מעדכנים פרמטר גרסה בקישורי הקבצים ב־index.html לאחר שינוי, כדי למנוע טעינת גרסה ישנה ממטמון. שומרים על מזהים קיימים ועל קישורים ישירים למתכונים. בודקים חיפוש, סינון, פתיחה, רוחב נייד וטעינת תמונות. מאמתים build מוצלח ושהתוכן החי תואם לפני דיווח על פרסום.
