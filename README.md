# המתכונים של אמא
אתר עברי מותאם לנייד, עם חיפוש לפי שם או מרכיב, קטגוריות, סימון מצרכים והדפסה.

התוכן נמצא ב־recipes.js. כל מתכון כולל קישור לשיחה שממנה נלקח. לשמירת פרטיות, מעלים רק את המתכון והטיפים הרלוונטיים, ולא את מלוא השיחה.

## עדכונים
מוסיפים או מתקנים רשומה ב־recipes.js ושומרים לענף main. GitHub Pages מפרסם את הגרסה המעודכנת. אפשר לבקש בשיחת Codex זו להוסיף מתכון ולצרף קישור לשיחה המקורית.

כל עדכון חייב להתחשב בהודעות ההמשך ובתיקוני הכמויות. אין לסמן מתכון כבדוק אם לא תועד שהוכן בהצלחה. יש לשמור מזהים יציבים, כדי שקישורים למתכונים ימשיכו לעבוד.
